Giới thiệu

Xin chào! Tôi là Lê Dương Bảo, sinh viên ngành Công nghệ Thông tin tại Học viện Hàng không Việt Nam (VAU). Tôi định hướng phát triển trở thành Software Engineer / Data Engineer chuyên sâu về Financial Platforms, Xử lý giao dịch thông lượng cao (High-Throughput), Backend & Phân tán, và Ứng dụng AI.

Tôi có kinh nghiệm thực chiến trong việc thiết kế kiến trúc tài chính với Java 21, Spring Boot, LMAX Disruptor (>15.000 TPS), Write-Ahead Log (WAL), Redis Caching, Kafka, PostgreSQL & Oracle SQL; đồng thời thành thạo xây dựng Backend APIs với Node.js/Python, cơ sở dữ liệu phân tán và pipeline Computer Vision thời gian thực.

Trong chương trình đào tạo AWS First Cloud AI Journey (FCAJ), tôi đã có cơ hội học tập, nghiên cứu và phát triển các giải pháp Cloud & AI thực tế, đồng thời 2 lần vinh dự nhận Học bổng Khuyến khích học tập tại Học viện Hàng không Việt Nam.

    Xây dựng hệ thống lõi giao dịch tài chính với Java 21, Spring Boot, kiến trúc RingBuffer LMAX Disruptor (>15.000 TPS), Write-Ahead Log (WAL), Redis Idempotency và chuẩn bản tin FIX Protocol.

    Xây dựng pipeline xử lý hình ảnh và video thời gian thực kết hợp Ultralytics YOLO11, tracking ByteTrack, nhận diện InsightFace và OpenCV.

    Triển khai ứng dụng trên nền tảng AWS (EC2, S3, IAM), đóng gói container với Docker Compose, Message Queue (Kafka), In-Memory Cache (Redis) và giám sát hệ thống với Prometheus & Grafana.
