Giới thiệu

Xin chào! Tôi là Lê Dương Bảo, sinh viên ngành Kỹ thuật Công nghệ Thông tin tại Học viện Hàng không Việt Nam (VAU). Tôi định hướng phát triển sự nghiệp chuyên sâu trong 3 lĩnh vực: Data Engineering (Financial Pipelines & Data Systems), Backend / Cloud Engineering và Ứng dụng AI / Computer Vision.

Thông qua các dự án phần mềm và nghiên cứu khoa học thực tế, tôi có kinh nghiệm thiết kế pipeline xử lý dữ liệu tài chính 50.000 giao dịch với Python, Apache Kafka, PostgreSQL DWH, Docker Compose; xây dựng kiến trúc lõi giao dịch hiệu năng cao (>15.000 TPS) với Java 21, Spring Boot, LMAX Disruptor, WAL, Redis Idempotency; đồng thời thành thạo phát triển Backend APIs (Node.js/Express, Flask), triển khai hạ tầng đám mây AWS (EC2, S3, IAM) và pipeline thị giác máy tính (Ultralytics YOLO11, ByteTrack, InsightFace, OpenCV).

Tôi từng hoàn thành kỳ thực tập 3 tháng First Cloud AI Journey (FCAJ) do AWS bảo trợ, đồng thời 2 lần liên tiếp vinh dự nhận Học bổng Khuyến khích học tập Loại Giỏi (2025–2026) tại Học viện Hàng không Việt Nam.

Chuyên môn chính

  • Financial Core & High-Throughput Systems

    Xây dựng hệ thống lõi giao dịch tài chính với Java 21, Spring Boot, kiến trúc RingBuffer LMAX Disruptor (>15.000 TPS), Write-Ahead Log (WAL), Redis Idempotency và chuẩn bản tin FIX Protocol.

  • Database Engineering & Advanced SQL

    Thiết kế Star Schema DWH, tối ưu hoá truy vấn với Index B-Tree, Partitioning bảng giao dịch, viết PL/pgSQL & Oracle Stored Procedures và phân tích EXPLAIN ANALYZE.

  • Computer Vision & Edge AI

    Xây dựng pipeline xử lý hình ảnh và video thời gian thực kết hợp Ultralytics YOLO11, tracking ByteTrack, nhận diện InsightFace và OpenCV.

  • Cloud Infrastructure & Observability

    Triển khai ứng dụng trên nền tảng AWS (EC2, S3, IAM), đóng gói container với Docker Compose, Message Queue (Kafka), In-Memory Cache (Redis) và giám sát hệ thống với Prometheus & Grafana.
